# Servo Melody Voice Pro

Aplikasi web modern pengendali Animatronic Servo & Melody berbasis React, Vite, Tailwind v4, dengan integrasi Gemini AI dan kontrol suara/audio responsive.

Dilengkapi `@google/generativeai`, `bottleneck` (Anti-Limit), dan `octokit` (GitHub API) di `src/lib/agentBridge.js`.
